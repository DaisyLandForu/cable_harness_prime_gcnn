## 3. 分实例关键信号

### `real_01`（最强正向，λ 敏感）

| method | seed0 nodes/wall | seed1 nodes/wall |
|---|---|---|
| default | 154 / 62s | 22 / 28s |
| rl-gcnn | 132 / 115s | 65 / 59s |
| λ=0.25 | **216 / 182s**（变差） | 23 / 43s |
| **λ=0.5** | **14 / 26s** | **12 / 23s** |
| λ=1.0 | 14 / 26s | 12 / 23s |
| gated | 105 / 92s（门控伤到收益） | 14 / 25s |

→ λ≥0.5 在此实例上复现阶段 A 的大幅收益；λ=0.25 不足；**门控关掉 depth=0 偏置后收益大减**。

### `real_05`（λ 过高有害）

| method | seed0 | seed1 |
|---|---|---|
| rl-gcnn | **18 / 27s** | 61 / 70s |
| λ=0.25 | 22 / 31s | 45 / 59s |
| λ=0.5 | **147 / 135s** | 15 / 34s |
| λ=1.0 | **463 / 387s** | 16 / 38s |
| gated | 144 / 131s | 15 / 34s |

→ 同一 λ=0.5 在 `real_01` 极好、在 `real_05@seed0` 很差；λ=1.0 放大灾难。门控未缓解。

### `real_09`（小实例噪声）

- λ=0.5 seed0：8→35 节点（仍差）
- gated seed0：28 节点（略好于 35，仍差于基线）
- λ=0.25 / 1.0 seed0：接近 gcnn（7 / 6）

### `real_08` / `real_03`

- `real_08`：各 prim 相对 gcnn 略减节点（69→~52），仍慢于 default；gated 反而到 79。
- `real_03`：全部 1 节点 root 解，方法无差别。

## 4. 结论（A-extend）

1. **λ=0.5 仍是扫描中的默认最优折中**：整体与 hard 子集上相对纯 GCNN 最好；λ=0.25 偏弱，λ=1.0 方差过大。
2. **收益不稳定、跨实例符号会翻转**：`real_01` 大赢 vs `real_05`/`real_09` 大输，说明纯 decode 偏置缺少实例自适应。
3. **当前小实例门控（depth≥1 + 要求 S 非空）未达预期**：未能修好小实例，还削弱了 `real_01` 的关键收益 → **不建议作为默认开启**。
4. **相对 SCIP default**：扩展集上仍未全面超越；Prim decode 的定位仍是“纠偏弱势 GCNN”，不是端到端最优求解器。
5. **阶段 A 扩展目标已完成**：λ 扫描、更多实例、门控均有可复现数字；继续只拧 decode 的边际有限。
